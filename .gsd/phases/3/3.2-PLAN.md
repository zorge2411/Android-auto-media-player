# Plan 3.2: Final performance and UI polish

## Context
Before a Play Store or wide distribution release, the app needs minor performance optimizations and UI polish to ensure a smooth experience on real car head units.

## Goal
Address observable performance issues and UI gaps found in logcat and code review.

## Approach
1. **Binder transaction size** — Reduce Coil thumbnail decode size from 512×512 to 256×256 px. A 512×512 ARGB_8888 bitmap is exactly 1 MB, which sits right at the Binder IPC limit and causes "Large outgoing transaction" warnings on Qualcomm head units.
2. **Loading state for Favorites** — `FavoritesScreen` showed "No favorites yet" briefly while loading because it lacked an `isLoading` flag. Add one so users see "Loading favorites…" instead of an empty-state flash.

## Tasks
- [x] Shrink Coil thumbnail request size in `BrowseScreen.prefetchThumbnails()`
- [x] Add `isLoading` state to `FavoritesScreen` with proper template messaging
