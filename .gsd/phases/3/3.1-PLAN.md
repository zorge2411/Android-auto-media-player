# Plan 3.1: Implement production-ready `HostValidator`

## Context
`AutoMediaService.createHostValidator()` currently returns `HostValidator.ALLOW_ALL_HOSTS_VALIDATOR`. This is required for sideloaded debug builds because unsigned apps are rejected by the standard host signature check. However, it is a security risk for any Play Store distribution.

## Goal
Implement a `HostValidator` that:
1. Allows all hosts in **debug** builds (for development / sideloading).
2. Uses the standard Google allowlist in **release** builds (Play Store requirement).

## Approach
Use `BuildConfig.DEBUG` to switch between the two validators at runtime:
- Debug → `HostValidator.ALLOW_ALL_HOSTS_VALIDATOR`
- Release → `HostValidator.Builder(applicationContext).addAllowedHosts(androidx.car.app.R.array.hosts_allowlist).build()`
